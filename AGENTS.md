# FlowSight Students site

- Keep this repository independent from the FlowSight Solo site at `solo.flowsight.site`.
- The home page is an organization pilot concept. Keep checkout closed until payment, delivery, activation, recovery and updates have been verified for all three desktop platforms.
- Use real product captures from `public/product`. Label sample data and proposed features clearly.
- Prices are final one-time amounts: €25 per license for 1–99 and €10 per license for 100–500 in one order.
- Organizations see only aggregate license activation. Focus averages and category totals require voluntary contributions from at least 10 learners; never expose person-level activity.
- Keep keyboard navigation, system dark mode, reduced motion and mobile layouts working.
